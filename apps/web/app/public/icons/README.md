# Showcase icon assets

`../icon-data.ts` contains a subset of SVG geometry from these free sets:

- [Tabler Icons](https://github.com/tabler/tabler-icons), `@tabler/icons@3.41.1`, MIT.
- [Phosphor Icons](https://github.com/phosphor-icons/core), `@phosphor-icons/core@2.1.1`, Light weight, MIT.
- [HugeIcons](https://github.com/hugeicons/hugeicons), `@hugeicons/core-free-icons@4.1.1`, MIT. The upstream [license and README](https://github.com/hugeicons/hugeicons#license) cover the free core pack used here.

Lucide provides the Reflow default; see the package NOTICE. None of these packages is installed as a runtime dependency.
